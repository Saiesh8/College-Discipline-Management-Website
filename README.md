🎓 College Discipline Management Website
A web-based platform to help college administrators manage and monitor student discipline records efficiently.

🚀 Tech Stack
Frontend: HTML, CSS, JavaScript, Bootstrap

Backend: PHP

Database: MySQL

🧰 Features
👨‍🏫 Admin login and dashboard

📝 Add, update, and delete student discipline records

🔍 Search and filter students by department, name, or roll number

📄 View individual student discipline history

🔐 Secure authentication and session management

📊 Responsive and user-friendly interface
